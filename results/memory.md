# Qwen3-1.7B 量化 - 内存

## 配置

* 运行环境：llama.cpp
* GPU 卸载：99 层
* 上下文长度：2048
* 生成长度：128 tokens
* 重复次数：3
* VRAM 指标：相对于基线的 GPU 显存峰值增量
* RAM 指标：进程工作集峰值

## 结果

| 量化格式   | 峰值 VRAM (MiB) | 峰值 RAM (MiB) |
| ------ | ------------: | -----------: |
| F16    |          3713 |         3780 |
| Q8_0   |          2166 |         2163 |
| Q4_K_M |          1468 |         1476 |

## 说明

* 每个模型均测试 3 次。
* 报告结果采用中位数。
* VRAM 的测量值为每次运行前 GPU 显存基线之上的增量。
* 后台运行的 GPU 应用程序可能会引入一定的测量噪声。

## 分析

量化可以显著降低模型运行时的内存占用。

与 F16 相比：

* Q8_0 将峰值 VRAM 降低了约 41.7%，将峰值 RAM 降低了约 42.8%。
* Q4_K_M 将峰值 VRAM 降低了约 60.5%，将峰值 RAM 降低了约 61.0%。

运行时内存占用的下降幅度小于 GGUF 文件大小的下降幅度。这是正常现象，因为运行时内存中不仅包含模型权重，还包括 KV Cache、计算缓冲区、CUDA 运行时缓冲区以及其他临时内存。

因此，模型文件大小与运行时内存占用之间具有很强的相关性，但它们并不是等价的指标。
